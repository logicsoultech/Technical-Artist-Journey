## Overview

Today's session was entirely practical — building an environment blending material from scratch in Unreal Engine 5.4. The technique enables a mesh (e.g. a rock) to blend naturally with surrounding terrain by detecting surface orientation in World Space and transitioning between two materials based on that data. This is a foundational technique that underpins landscape auto-materials, weather systems, and vertex paint workflows.

---

## Topic — Environment Blending

The goal of this technique is to make a material that **blends with its surrounding environment naturally** — for example, a rock embedded in the ground appears to merge with the soil at its base rather than looking like it was simply placed on top of it.

---

## Nodes Used & Their Functions

### 1. `VertexNormalWS`

Returns the surface normal of the mesh in **World Space**. This is needed to detect which faces are pointing upward relative to the world's gravity — regardless of the object's local rotation.

### 2. `TransformVector` (Tangent Space → World Space)

Converts the normal map from **Tangent Space** (local texture space) into **World Space**. This step is critical because in-game lighting calculations happen in World Space. Without this transform, the "up" direction detection would be inconsistent with the visual lighting result.

### 3. `Mask (B)` — Channel Z

Isolates the **Z (Blue) channel** from the World Space normal, which represents the vertical axis. A high value means the surface faces upward and should receive the blend material; a low value means the surface faces sideways and retains the base material.

- **High Z value** → surface faces up → blend material dominates
- **Low Z value** → surface faces sideways → base material dominates

Channel Z is used because Z is the vertical axis aligned with the world's gravity direction.

### 4. `Add` (value: 0.3)

Offsets the mask value to control **how far down the blend creeps** along the sides of the object.

| Value | Effect |
|---|---|
| Negative (e.g. –0.1) | Blend restricted to topmost surfaces only |
| Positive (e.g. 0.5) | Blend spreads higher up the sides — useful for moss on a rock |

### 5. `Power` (value: 100)

Sharpens the contrast of the blend transition.

| Value | Effect |
|---|---|
| High (100) | Hard, tight transition — appropriate for rocky cliffs |
| Low (5–10) | Soft, gradual transition — appropriate for soil or sand piles |

### 6. `Clamp` (Min 0, Max 1)

Ensures the mask value stays within the **0–1 range** before entering the Lerp Alpha. Without Clamp, negative values or values above 1.0 flowing into Lerp can produce visual artifacts. Clamp is a mandatory safeguard after any arithmetic operation.

### 7. `TexCoord[0]`

Supplies the standard UV coordinates of the mesh for texture sampling.

### 8. `Texture Sample` (×4)

| Texture | Function |
|---|---|
| Base Color — Material 1 (rock) | Base color of the primary material |
| Base Color — Material 2 (soil/grass) | Base color of the blend material |
| Normal Map — Material 1 (rock) | Surface detail of the primary material |
| Normal Map — Material 2 (soil/grass) | Surface detail of the blend material |

### 9. `Lerp` — Base Color

Blends the two base colors using the Clamp output as the Alpha.

- **Alpha = 0** → Material 1 (rock) fully visible
- **Alpha = 1** → Material 2 (soil/grass) fully visible

### 10. `Lerp` — Normal Map

Blends the two normal maps using the same Alpha. This step is **required** — each material has different surface detail, and failing to blend the normal maps produces incorrect lighting at the transition boundary.

---

## Node Flow

```
Normal Map
    ↓
TransformVector (Tangent → World)
    ↓
Mask — Channel Z (vertical axis)
    ↓
Add 0.3 (offset blend boundary)
    ↓
Power 100 (sharpen transition)
    ↓
Clamp 0–1 (sanitize value)
    ↓ (Alpha)
Lerp Base Color ──→ Base Color Output
Lerp Normal Map ──→ Normal Output
```

### When This Technique Is Too Expensive

- **Mobile** — too heavy; use a simplified blending approach
- **Small or distant objects** — visual benefit does not justify the GPU cost
- **Background / non-hero assets** — consider LOD or simplified materials

## Key Takeaways

1. **Transferable logic** — the same math applies in Unity ShaderGraph, Godot VisualShader, and custom HLSL. The engine changes; the principles do not.
2. **Foundational system** — landscape auto-materials, snow/wetness shaders, weather systems, and vertex paint workflows all build on this same technique.
3. **TA mindset** — build the system once and make it reusable by the entire art team. That is the core value a Technical Artist provides.
4. **Snow variant** — same graph, different textures. Replace soil texture with snow, raise the Add value to ~0.5–0.7, lower Power to ~50, and add high Roughness (snow is matte).
5. **Normal map must always be blended** — if only Base Color is blended, lighting breaks at the transition boundary.
6. **TransformVector is not optional** — without it, the "up" direction detection is relative to local object space, not the world, and the blend will behave incorrectly on rotated meshes.
